

# Admin Features Implementation Files

## Features Implemented
- Admin dashboard and UI in frontend (admin-only dropdown, navigation, and pages)
- Admin endpoints in backend for:
	- Downloading all survey data as a file
	- Viewing all survey submissions
	- Admin authentication and role enforcement
- Admin registration and login support

## Files Changed or Created

### Backend
- src/controllers/surveyController.ts  (admin endpoints: downloadAllSurveyData, getAllSurveySubmissions, admin role checks)
- src/routes/surveyRoutes.ts  (registers admin endpoints)
- src/controllers/authController.ts  (admin registration/login logic)
- src/models/userModel.ts  (admin role support)
- src/models/surveyModel.ts  (admin queries for all submissions)
- src/services/authService.ts  (admin role logic)
- downloads/  (temporary storage for exported files)
- test/auth-survey-api.test.ts  (tests admin/non-admin download and all-submissions behavior)


### Frontend
- src/pages/SeeAllSubmissionsPage.tsx  (admin view of all submissions, download buttons, download-all-data button, admin-only access/redirect)
- src/pages/CreateSurveyPage.tsx  (admin survey creation, admin-only access/redirect)
- src/contexts/AuthContextOnly.tsx  (add user.role to context)
- src/contexts/AuthContext.tsx  (propagate user.role from backend, store in context)
- src/hooks/useAuth.ts  (used for admin checks in pages)
- src/components/Navbar.tsx  (admin dropdown menu)
- src/App.tsx  (routing for admin pages)

## Packages Used
- fs (Node.js built-in, for file writing)
- path (Node.js built-in, for file paths)
- jsonwebtoken (for admin JWT verification)
- express (backend API)
- react, react-router-dom (frontend UI/routing)

---
This list includes all files and packages changed or created for the full admin experience: admin dashboard, all submissions, download, admin-only UI, and backend role enforcement.
