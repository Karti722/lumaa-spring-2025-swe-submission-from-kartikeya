
# Admin Survey Data File Creation Endpoint

This document summarizes the implementation and behavior of the admin-only endpoint for downloading all survey data as a file.

---

## Endpoint

- **POST** `/api/admin/download-survey-data`
  - Admin-only (requires JWT token with admin role)
  - Accepts body: `{ "downloadFileType": "json" | "csv" | "txt" }`
  - Returns: File download (Content-Disposition: attachment)

## Implementation Details

- **Controller:** `src/controllers/surveyController.ts`
  - Function: `downloadAllSurveyData`
  - Verifies admin token from cookie or Authorization header
  - Gathers all survey data (with questions)
  - Serializes data to requested format (JSON, CSV, or TXT)
  - Writes file to `downloads/` directory with a timestamped name
  - Responds with file as a download
  - File is deleted from disk ~10 seconds after download starts (for cleanup)

- **Route:** `src/routes/surveyRoutes.ts`
  - Registers the endpoint and links to the controller

## File Behavior

- File is created in `downloads/` directory (e.g., `survey_data_20250817.json`)
- File is available for about 10 seconds after download, then deleted automatically
- If you want to keep the file, comment out or remove the `setTimeout(() => fs.unlinkSync(filePath), 10000)` line in the controller

## Test Coverage

- **Test File:** `test/auth-survey-api.test.ts`
  - Tests admin can download survey data in all formats
  - Tests non-admins are forbidden
  - Verifies correct response headers and status
