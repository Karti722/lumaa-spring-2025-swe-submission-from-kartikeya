# Survey App API Endpoints for Thunder Client

---

1. Get All Surveys
Endpoint: http://localhost:5000/api/surveys
Method: GET
Headers:
  Content-Type: application/json

---

2. Create Survey
Endpoint: http://localhost:5000/api/surveys
Method: POST
Headers:
  Content-Type: application/json
Body (JSON):
{
  "title": "Test Survey",
  "description": "A test survey"
}

---


3. Get Survey Details
Endpoint: http://localhost:5000/api/surveys/1
Method: GET
Headers:
  Content-Type: application/json

---


4. Add Text Question
Endpoint: http://localhost:5000/api/surveys/1/questions
Method: POST
Headers:
  Content-Type: application/json
Body (JSON):
{
  "title": "Text Question",
  "questionType": "text"
}

---


5. Add Number Question
Endpoint: http://localhost:5000/api/surveys/1/questions
Method: POST
Headers:
  Content-Type: application/json
Body (JSON):
{
  "title": "Number Question",
  "questionType": "number"
}

---


6. Add Textarea Question
Endpoint: http://localhost:5000/api/surveys/1/questions
Method: POST
Headers:
  Content-Type: application/json
Body (JSON):
{
  "title": "Textarea Question",
  "questionType": "textarea"
}

---


7. Add Email Question
Endpoint: http://localhost:5000/api/surveys/1/questions
Method: POST
Headers:
  Content-Type: application/json
Body (JSON):
{
  "title": "What is your email address?",
  "description": "Please enter a valid email address so we can contact you if needed.",
  "questionType": "email"
}

---


8. Submit Survey Response
Endpoint: http://localhost:5000/api/surveys/1/submit
Method: POST
Headers:
  Content-Type: application/json
Body (JSON):
{
  "responses": [
    { "questionId": 1, "answer": "Sample text" },
    { "questionId": 2, "answer": "42" },
    { "questionId": 3, "answer": "Some long answer" },
    { "questionId": 4, "answer": "test@example.com" }
  ]
}

---


9. Get Survey Submission
Endpoint: http://localhost:5000/api/submissions/abc123-session-id
Method: GET
Headers:
  Content-Type: application/json

---


# Note
- Replace IDs with real values from your database as needed.
- All endpoints are unauthenticated.
- Radio/select/checkbox endpoints are omitted due to backend issue.
